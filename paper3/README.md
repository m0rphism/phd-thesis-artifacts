# Session Types in Reference-Passing Style
## Artifact Collection
### Paper 3

This directory contains the artifact for the paper

> H. Saffrich, Y. Nishida, and P. Thiemann.  
> **Law and order for typestate with borrowing.**  
> *Proc. ACM Program. Lang.,*  
> Vol. 8, OOPSLA2:1475–1503, 2024.  
> https://doi.org/10.1145/3689763

The artifact consists two parts located in two separate subdirectories:

- [`agda-algorithmic-typing`](agda-algorithmic-typing/) contains the mechanized soundness and decidability proofs for the algorithmic typing relation.

- [`rust-interpreter`](rust-interpreter) contains the implementation of an interpreter and typechecker.
