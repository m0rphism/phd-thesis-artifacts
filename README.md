# Session Types in Reference-Passing Style
## Artifact Collection

This repository contains the artifacts for the five papers presented in my
cumulative PhD thesis.

The artifact for each paper is located in a separate subdirectory:

-   [`paper1/`](/paper1/) contains the artifact for the paper:

    > H. Saffrich and P. Thiemann.  
    > **Relating functional and imperative session types.**  
    > *Log. Methods Comput. Sci.,*
    > 18(3), 2022.  
    > https://doi.org/10.46298/lmcs-18(3:33)2022

-   [`paper3/`](/paper3/) contains the artifact for the paper:

    > H. Saffrich, Y. Nishida, and P. Thiemann.  
    > **Law and order for typestate with borrowing.**  
    > *Proc. ACM Program. Lang.,*  
    > Vol. 8, OOPSLA2:1475–1503, 2024.  
    > https://doi.org/10.1145/3689763

-   [`paper4/`](/paper4/) contains the artifact for the paper:

    > H. Saffrich, J. Spaderna, P. Thiemann, and V. Vasconcelos.  
    > **Borrowing From Session Types.**  
    > *Proc. ACM Program. Lang.,*  
    > Vol. 9, OOPSLA2, Article 395, 2025.  
    > https://doi.org/10.1145/3763173

-   [`paper5/`](/paper5/) contains the artifact for the paper:

    > H. Saffrich.  
    > **Abstractions for multi-sorted substitutions.**  
    > In Y. Bertot, T. Kutsia, and M. Norrish, editors,
    > *15th International Conference on Interactive Theorem Proving, ITP 2024,
    > September 9-14, 2024, Tbilisi, Georgia,*  
    > volume 309 of LIPIcs, pages 32:1–32:19. Schloss Dagstuhl - Leibniz-Zentrum
    > für Informatik, 2024.  
    > https://doi.org/10.4230/LIPIcs.ITP.2024.32
