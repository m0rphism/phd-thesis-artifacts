# Session Types in Reference-Passing Style
## Artifact Collection
### Paper 1

This directory contains the artifact for the paper

> H. Saffrich and P. Thiemann.  
> **Relating functional and imperative session types.**  
> *Log. Methods Comput. Sci.,*
> 18(3), 2022.  
> https://doi.org/10.46298/lmcs-18(3:33)2022

The artifact consists of a single subdirectory,
[`agda-preservation-proof/`](agda-preservation-proof/), which contains an Agda formalization
of the type-preserving translation from VGR to GV (aka LFST).
